# Vehicle Speed Detection

Проект для обнаружения и отслеживания транспортных средств на дневном и ночном видео с помощью YOLOv8n.

## Возможности

* Обнаружение автомобилей, автобусов и грузовиков.
* Обнаружение пешеходов на ночном видео.
* Отслеживание объектов с помощью ByteTrack.
* Приблизительный расчёт скорости в км/ч.

## Используемые технологии

* Python
* OpenCV
* NumPy
* Ultralytics YOLOv8n

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запуск дневного видео:

```bash
python speed_detection.py
```

Запуск ночного видео:

```bash
python speed_night.py
```

Видео нужно поместить в папку `input` под именами `car.mp4` и `night.mp4`.

## Ограничения

Скорость рассчитывается приблизительно, так как размеры дорожного участка заданы вручную.
